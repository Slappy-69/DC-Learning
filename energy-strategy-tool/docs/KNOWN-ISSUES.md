# Known issues in the built program

Found on 2026-10-21 while writing the user guide, by checking the guide against the code on `main` (commit 441635e) and a full run of the T1 example; items 10–13 were found later. **Items 1–3, 6–11 and 13–19 are resolved** (19 was found in the Pego study, revision 3.1) (1–3, 8–11 and 14–18 in work package 11 on `feature/engine-fixes`, 2026-10-24, with Claude's recommendations accepted in advance by the owner; OPEN-QUESTIONS 68–76); (7 and 6 by the answers to OPEN-QUESTIONS 20 and 26) (2026-10-23, with the owner's approval). Each changes numbers or wording that the owner has seen, so ask the owner before fixing any of them (OPEN-QUESTIONS 31), one at a time, and record the answer here. Line numbers are for commit 441635e and will drift.

The user guide describes each one for engineers: chapter 54 ("Findings while writing this guide"), with details in chapters 16, 22, 37 and 47 (`user-guide/src/`).
